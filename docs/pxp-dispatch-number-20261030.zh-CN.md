# 发车时刻与车次对应修复（2026-10-30）

## 问题与修改

`DepartureListScheduleModeSlotEvaluator::EvaluateSlots` 在复制第二个及后续计时调度时刻时，读取的仍是首个时刻索引；复制下一周期时又用首时刻的车次覆盖副本，造成不同发车时刻串用同一车次。

修改 `src/departures.cpp`：按被复制到的时刻读取车次；重复周期保留原时刻身份。

修改 `src/departures_gui.cpp`：24 小时计划看板从该条记录的时刻车次开始解析，不使用代表车辆当前车次、上次发车记录或解挂残留状态。明确的本站手动车次仍优先；本站选择计时调度时使用该次发车时刻的车次。直线调度段继承显式车次；不提前执行条件跳转或子计划。

本次未修改列车模拟、自动待避、PBS、连挂解挂和存档字段。

## 同一车次显示两条记录

“到达＋出发”模式分别显示到达与出发：到达记录显示来向，出发记录显示去向；因此同一班次可以出现两条。这不是删除重复记录的依据。仅想查看发车时，请切换看板为“出发”。保留原生到达和出发模式。
