# 路点停车、车次中文与上游 p3 同步

## 最终行为

- 路点调度命令增加独立“停车”按钮：使用原生换向的全列通过距离和制动过程停车，不勾选换向时不强制掉头。等待结束后，按下一有效车站、路点、车辆段或连接目标比较合法方向；仍遵守游戏的换向设置、信号及 PBS。零等待时实际停稳一次再继续；有时刻表时沿用原生晚点补偿与等待规则。
- 路点可以设置“此处不更换／手动车次／计时调度车次”，经过指定路点才应用。设置未来命令不会立即改当前车次；经过其他车站不提前执行路点车次。支持共享调度、JSON 导入导出及存档重载。
- “前往连接”未指定车站时明确显示“任意车站”，仍可选定车站；沿用原来的货物、路签、速度、编组及独占认领限制。

## 5 号与 16 号的根因和验证

原始 `机务段模板.sav` 中，红色公司为公司 2。5 号主车辆 ID 229，16 号主车辆 ID 635。不是连接条件不符：候选条件检查通过，5 号也最终会连上 16 号，但原实现先从前向寻找长绕行路线。

两个缺口共同造成绕行：`UpdateOrderDest` 未把无确定站点的前往连接命令作为可判断换向的目标；`YapfTrainCheckReverse` 使用普通目标评估器，不能在尚未认领目标时识别身后的等待连接列车。

修复使用连接目标评估器，从列车两个物理端执行只读 YAPF 比较，保留独占目标过滤和原生换向代价。查询不创建轨道预约；实际换向、认领和行驶仍走原生过程。原存档副本实际运行在第 402 个观察游戏刻，ID 635 已归入 5 号的车辆链，证明发生真实连挂。原文件 SHA256 与备份副本一致，没有改写用户存档。

## 使用与兼容

打开调度计划，选中路点，可独立点击“停车”和“换向”，下方车次选择决定此处之后的车次。换向选项是否生效还受游戏难度设置约束。若需长时间等待，可按原时刻表／调度规则设置等待时间。勾选停车并不绕过 PBS，也不保证轨道本身禁止倒行时能倒行。

新程序可以读取旧存档；新保存的路点停车功能带明确版本标记，旧程序不支持时会拒绝读档，避免默默当作通过路点。联机各端应使用同一新版程序。
