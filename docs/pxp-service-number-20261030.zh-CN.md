# 时刻表固定车次与出发看板（2026-10-30）

> 历史版本说明：此界面已被“调度计划按停站命令设置车次”替代。当前说明见 `pxp-station-service-20261030.zh-CN.md`。

列车时刻表底部增加车次下拉栏。选择“设置本车固定车次……”后输入，例如 G123；选择“使用计时调度车次”或清空输入，恢复原来的计时调度发车车次。取消输入不改变设置。固定车次按本列车保存，不按共享调度表统一修改。

两个来源互斥生效，不删除原有计时调度车次定义，也不修改条件调度对原有发车记录的判断。固定车次属于显示标识，不是改变计时调度语义的指令。

出发看板有生效车次时显示车次并隐藏该行的载具名称；没有车次时保留原有名称显示选项。默认显示载具名称的看板自动获取计时调度车次，无需另外打开车次显示选项。固定车次优先于计时调度；开启“载具窗口中显示车次”时，标题栏也采用相同来源优先级。

## 实现与兼容

- `BaseConsist::fixed_service_number` 使用 TinyString，空值即采用计时调度；沿用编组属性复制流程保留设置。
- `CmdSetVehicleServiceNumber` 经原生同步命令执行，检查车辆有效性、主车辆、列车类型、所属公司和长度；测试阶段不写入。
- 新命令追加到命令列表末尾，不移动原有命令编号。
- 独立存档标记 `pxp_fixed_service_number`，车辆及车辆订单备份均保存。旧存档默认使用计时调度。带新标记的存档需要支持此功能的程序，不能承诺旧程序读取新存档。
- 自动待避、PBS、连挂解挂、速度优先级和调度执行逻辑未修改。
- 切换固定车次不删除计时调度定义；固定车次可重复，不作跨公司唯一性限制。
